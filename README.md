# 🛡️ CyberShield

**CyberShield** is a modern cybersecurity awareness and utility website designed to help users understand and handle common online security risks.

The project provides a simple and interactive interface for exploring cybersecurity-related tools and information in one place.

## 🚀 Live Demo

[Visit CyberShield](https://flourishing-concha-e5d29c.netlify.app/)

## ✨ Features

* 🔍 **Link Checker** — Interface for checking potentially suspicious links.
* 🤖 **Cybersecurity Chatbot** — Interactive interface for cybersecurity-related assistance.
* 🔐 **Password Generator** — Generates strong password combinations for improved account security.
* 🚨 **Scam Detector** — Interface designed to help users identify potentially suspicious or scam-related content.
* 📱 **Responsive Design** — Designed to provide a clean experience across different screen sizes.
* 🎨 **Modern UI** — Cybersecurity-themed interface with an interactive and visually engaging design.

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — Interactivity and functionality
